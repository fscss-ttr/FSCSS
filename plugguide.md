
# FSCSS module 

Reusable module libraries for FSCSS that extend the ecosystem with additional utilities, UI components, themes, helpers.

## Installation

Some modules are available using the built-in `_init` system.

### published module Usage

```css
@import(exec(_init name))
```
Or 

```css

@import((*) from name)

```
